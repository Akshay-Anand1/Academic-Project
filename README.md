# Academic Project

A collaborative, full-stack machine learning project focused on intelligent prediction, explainability, and user-facing analytics. The system combines computer vision, backend APIs, and a modern frontend dashboard to turn raw inputs into actionable insights.

## Overview

This project brings together data science, engineering, and product design to build an end-to-end solution that supports:

- Video and dataset ingestion
- Data preprocessing and feature engineering
- ML model training and evaluation
- Explainable AI insights using SHAP
- Secure API-driven backend services
- Interactive dashboard-based decision support
- Prediction history and user-controlled scenario exploration

## Key Features

- Video upload and analysis workflow
- Predictive modeling using gradient-boosted approaches such as XGBoost and LightGBM
- NLP and structured data analysis support
- Computer vision and video-based feature extraction
- Explainability dashboards for model interpretation
- What-if simulation controls for interactive exploration
- Hook strength estimation and visualized output metrics
- Prediction history and reporting
- Secure, scalable backend architecture with FastAPI
- Responsive frontend built with Next.js and Tailwind CSS

## Project Workflow

1. Users upload datasets or video inputs through the frontend.
2. The backend validates and preprocesses the incoming data.
3. ML models analyze the data and generate predictions.
4. SHAP and related explainability tools help interpret the results.
5. Users can explore outputs, compare scenarios, and review prediction history.
6. The system exposes insights through a clean, interactive product interface.
